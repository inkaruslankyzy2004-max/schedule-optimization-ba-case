# Оптимизация расписания учебного центра — Business Analysis Case Study

## О проекте

Pet project по бизнес-анализу, основанный на обезличенном кейсе из деятельности учебного центра. Проект посвящён оптимизации параллельных учебных групп и снижению количества ненужных изменений расписания для существующих учеников.

## Бизнес-проблема

Учебному центру необходимо было устранить ненужные параллельные группы. Изначально для решения проблемы было сформировано новое расписание для большого количества существующих клиентов. В результате изменения затронули не только учеников, непосредственно связанных с параллельными группами, но и учеников, чьё текущее расписание можно было сохранить. Около 80 из 200+ существующих клиентов (≈40%) после изменения расписания не имели подходящего варианта и нуждались в дополнительном согласовании.

## Цель анализа

Разработать процесс оптимизации параллельных групп, при котором изменения расписания применяются только к ученикам, которых непосредственно затрагивает проблема.

### Метрика успеха

Не более **10% учеников**, для которых не удалось найти подходящий вариант расписания, должны направляться на индивидуальное рассмотрение руководству. Показатель измеряется после завершения процесса формирования нового расписания.
> Целевое значение 10% является проектным ориентиром и требует подтверждения со стороны бизнеса.

## Подход к решению

Вместо массового изменения расписания предлагается:

1. Выявить параллельные группы.
2. Определить затронутых учеников.
3. Сохранить расписание незатронутых учеников.
4. Определить ограничения для затронутых учеников.
5. Найти подходящую существующую группу.
6. Проверить вместимость, преподавателя, аудиторию, оборудование, уровень и время.
7. Предложить подходящий вариант ученику/родителю.
8. Получить подтверждение.
9. Изменить только необходимое расписание.
10. Если подходящего варианта нет — передать список учеников руководству на индивидуальное рассмотрение.

## Основные бизнес-правила

* Количество учеников в группе не должно превышать **10 человек**.
* В группе должен быть доступный преподаватель.
* Для перераспределения в первую очередь используется существующая подходящая группа.
* Если подходящей существующей группы нет, новая группа может быть создана при наличии свободного временного слота и доступного преподавателя.
* Расписание ученика не должно изменяться, если ученик не относится к группе, которую необходимо перераспределить.
* Предпочтения клиента учитываются, но не могут нарушать обязательные ограничения учебного центра.

## Ключевой результат

Предлагаемый TO-BE процесс переносит точку принятия решения **до изменения расписания**: сначала определяется, кого действительно затрагивает проблема, и только после этого рассматривается изменение расписания.

Это позволяет сохранить расписание незатронутых учеников и сосредоточить работу по перераспределению только на необходимых случаях.

## Примечание

Проект основан на обезличенном и обобщённом бизнес-кейсе. Персональные данные, названия клиентов и конфиденциальная информация не раскрываются. Количественные показатели приведены в обобщённом виде исключительно для демонстрации бизнес-кейса.
